# ChatGPT Auto Read

An independent Microsoft Edge extension that starts ChatGPT’s built-in Read Aloud for new replies. The toolbar popup lets you toggle automatic playback and set the speed from 0.5× to 2×.

## Install v1.2.6 in Edge

1. Download [ChatGPT-Auto-Read-v1.2.6.zip](ChatGPT-Auto-Read-v1.2.6.zip) and extract it.
2. Open `edge://extensions`, enable Developer mode, and select **Load unpacked**.
3. Select the extracted folder containing `manifest.json`, then refresh your ChatGPT tab.

Keep the extracted folder while using the unpacked extension. The Edge Add-ons submission is under review.

Known issue: refreshing a conversation may occasionally replay an existing reply.
