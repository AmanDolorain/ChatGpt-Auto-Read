# ChatGPT Auto Read Privacy Policy

ChatGPT Auto Read is an independent browser extension that starts the built-in Read Aloud feature on chatgpt.com.

## Page access and local processing

The extension reads rendered page elements and reply text in memory to identify new replies and detect when a reply is ready to be read. It activates ChatGPT's Read Aloud controls and applies the selected playback speed. The extension does not persist chat messages or use them for analytics. The extension itself does not transmit chat content, account details, or browsing history to the developer or to a separate service.

## Local settings

The browser stores the Auto Read switch and playback speed locally using extension storage. These settings can be cleared by removing the extension.

## ChatGPT service

Read Aloud is provided by ChatGPT. ChatGPT handles its own audio and service requests under OpenAI's privacy policy at https://openai.com/policies/privacy-policy/.

## Contact
